# Estera Bulkiewicz — Portfolio

A minimal, high-performance portfolio website built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. It features a custom interactive HTML5 Canvas background, a direct contact form via Web3Forms, and integrated WhatsApp messaging.

## ✨ Features

* **Interactive Canvas Background**: Custom geometric/hexagonal particle network rendered via HTML5 Canvas with mouse interaction and scroll-triggered animations using `IntersectionObserver`.
* **Direct Web3Forms Integration**: Asynchronous, serverless client-side email delivery directly to inbox without requiring desktop `mailto:` popups.
* **Instant WhatsApp Link**: Direct click-to-chat integration using WhatsApp's universal URI scheme with pre-filled message templates.
* **Modern Minimal Design**: Clean typography, crisp grid alignments, and responsive layouts styled using Tailwind CSS.
* **Optimized Build**: Powered by Vite for fast HMR during development and lean production bundles.

---

## 🛠️ Tech Stack

* **Frontend**: React 18, TypeScript, Vite
* **Styling**: Tailwind CSS, Framer Motion
* **Contact & APIs**: Web3Forms API, WhatsApp Click-to-Chat API
* **Deployment**: Vercel
